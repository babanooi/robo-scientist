# 当前路线决议：纯软件虚拟实验

版本：v1.0
日期：2026-09-05
适用范围：RoboScientist 作品开发、演示和提交候选包

## 决议

本项目当前不要求线下操作 ArmPi，也不把机械臂上电、树莓派部署或实机采集作为软件交付的前置条件。公共演示路线固定为：

```text
任务输入 → 科学计划 → P0 虚拟执行 → 结构化评价 → 失败归因
→ 单参数候选 Skill → P1 虚拟验证 → 重复对照与版本决策
```

运行时使用仓库内的 `roboscientist.virtual_workcell`（纯 Python、确定性、无外部 ROS 依赖），结果必须带有以下来源字段：

```text
data_source=simulation
runtime_status=simulation_runtime_verified
runtime_name=roboscientist.virtual_workcell
engine=python_deterministic
synthetic=true
physical_robot_connected=false
```

## 作品能证明什么

- 自然语言任务可以转成结构化实验计划；
- P0 的失败证据可以改变下一轮参数；
- P1 只修改一个允许的参数族，并在相同场景和评价口径下复验；
- 轨迹、障碍物、碰撞预测、评价、失败分析和重复验证结果可追溯；
- Web 前端和 HTTP API 可以独立启动、调用和复现。

## 不能表述什么

当前结果不是 ArmPi 实机、Gazebo/MoveIt2 或物理动力学证据。禁止使用以下表述：

- “机械臂已经完成真实抓取”；
- “Gazebo/MoveIt2 已验证”；
- “已获得真实路径最优解”；
- “真实抓取成功率提升”。

如果官方验收把 Gazebo/MoveIt2 或真实实验仪器作为硬性条件，本路线只能作为软件原型/软件虚拟工作单元候选包，必须补对应运行证据后才能升级结论。

## 运行与验收入口

```sh
.venv/bin/python -m roboscientist.web.server \
  --host 127.0.0.1 --port 8010 --data-root data/demo
```

浏览器打开 `http://127.0.0.1:8010/`，选择 Simulation，运行“P0 → P1 科研闭环”，再点击“重复验证 P0 / P1（10 次）”。

一键生成提交候选包：

```sh
.venv/bin/python scripts/generate_virtual_submission.py
```

脚本不会读取、复制或输出 `.env` 和 API Key。
