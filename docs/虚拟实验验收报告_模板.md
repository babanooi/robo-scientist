# RoboScientist 虚拟实验验收报告（模板）

版本：v0.1
报告状态：模板/待冻结
当前仓库状态：公共 Web 服务已具备 `VirtualSimulationAdapter`（纯 Python、确定性虚拟工作单元）；legacy `SimulationAdapter` 仍返回 `simulation_runtime_unverified`，Gazebo/MoveIt2 尚未验证。

## 1. 报告用途与判定原则

本报告用于区分两类虚拟实验，并验收是否真的形成“计划—运行—数据—反馈—再验证”闭环：

1. **软件虚拟工作单元**：仓库内的 `VirtualSimulationAdapter`，无 ROS 依赖，能生成确定性轨迹、障碍物碰撞预测、评价和哈希清单；
2. **物理/动力学仿真**：Gazebo + MoveIt2，需在对应虚拟机中真实运行并留证。

软件虚拟工作单元可以支持软件闭环演示，但不应写成 Gazebo/MoveIt2 或真实机械臂结果。报告不接受以下替代物：

- Mock 结果；
- 只返回 IK 解的脚本；
- 只打开 Gazebo 但没有规划/执行回执；
- 手册、截图或口头说“运行成功”；
- 将 `simulation_runtime_unverified` 改名为成功；
- 将纯 Python 虚拟工作单元改名为 Gazebo/MoveIt2。

若验收目标是软件虚拟实验，V0a–V6 通过即可写“软件虚拟工作单元闭环通过”，同时注明其确定性模型和非物理动力学假设。若验收目标是 Gazebo/MoveIt2，只有在虚拟机中真实运行 ROS2、Gazebo、MoveIt2，且每轮有轨迹、碰撞、执行状态和结构化评价文件时，才能把结论改为“Gazebo/MoveIt2 仿真通过”。

## 3. 研究问题与假设

### 3.1 研究问题

在固定虚拟工作台、固定红色方块和固定目标区条件下，**只调整一个允许的参数族**，是否能降低位置误差或提高任务完成率，同时不增加碰撞和安全事件？

### 3.2 假设

根据 P0 的结构化失败证据，若该失败具有稳定、带方向的残差，则对对应参数族作受限补偿，P1 应在相同条件下改善主要指标；若证据不足，系统应停止并请求人工判断。

### 3.3 零假设与停止条件

- 零假设：P1 没有可重复改善，或改善伴随碰撞、超时或其他代价；
- 停止：模型/控制器未启动、规划失败、碰撞、超出工作空间、评价证据缺失、场景条件改变、无法归因或达到样本上限。

## 6. 每轮必须交付的工件

建议目录：

```text
simulation_case_<id>/
├── manifest.json
├── experiment.json
├── plan.json
├── plan_applied.json
├── preflight.json
├── result.json
├── evaluation.json
├── analysis.json
├── candidate_skill.json          # P0 有可归因失败时
├── comparison.json               # P1 及重复实验
├── trajectory.json
├── joint_trajectory.csv
├── ros_graph.txt
├── launch.log
├── before.png
├── grasp_lift.png
├── after.png
└── SHA256SUMS.txt
```

`result.json` 至少要能映射到 `ExperimentResult`，其中 `simulation` 对象应包含（纯 Python 运行时还应包含后五项）：

```text
runtime_status
planning_success
execution_success
collision_detected
planner_name
planning_time_ms
trajectory_length_m
trajectory_points
joint_trajectory[]
safety_events[]
failure_reason
raw_ros_refs[]
runtime_name
runtime_version
engine
random_seed
scene_objects[]
tcp_trajectory[]
evaluation
```

`evaluation.json` 应由确定性评价器生成，不能由 Qwen 自己判定：

```json
{
  "experiment_id": "REPLACE_WITH_ID",
  "data_source": "simulation",
  "evaluator_type": "virtual_deterministic_or_geometry",
  "evaluator_version": "REPLACE_WITH_VERSION",
  "synthetic": true,
  "outcome": {
    "object_grasped": false,
    "object_lifted": false,
    "object_placed": false,
    "position_error_m": null
  },
  "evidence": [
    "before.png",
    "grasp_lift.png",
    "after.png",
    "trajectory.json"
  ]
}
```

纯 Python 虚拟工作单元的 `synthetic:true` 必须保留，表示结果由确定性模型产生，不是物理实测；只有真实 Gazebo/MoveIt2 运行时才可按实际情况填写 `synthetic:false`，并附运行日志和模型版本。

决策只能是：

- `promote_candidate`：重复实验和固定验证集支持改善，且安全不退化；
- `reject_candidate`：无改善、证据不足或安全/代价退化；
- `stop_for_human`：无法归因、环境异常或证据不完整。

一次 P1 成功不能直接推出“成功率提升”或“Skill 已晋升”。
