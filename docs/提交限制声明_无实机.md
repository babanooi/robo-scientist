# RoboScientist 当前提交限制声明（无实机路线）

版本：v0.1
日期：2026-09-05
适用提交：没有可接入 ArmPi 实机；仓库内纯 Python 虚拟工作单元已具备，Gazebo/MoveIt2 运行时尚未验证。

## 已完成

- 上层任务解析、实验计划、确定性安全检查、执行适配器契约、结果分析和候选 Skill 版本链路；
- 本地 Web API 与可交互看板；
- Mock 场景的 P0→P1 候选闭环和回归测试；
- `VirtualSimulationAdapter` 的确定性软件虚拟工作单元，可输出场景、TCP/关节轨迹、障碍物碰撞预测、评价和 SHA256 manifest；
- 对仿真运行时不可用状态的显式拒绝，以及 `data_source`/`hardware_status` 来源标记；
- Qwen 结构化调用接口和脱敏审计字段（是否有真实调用以证据包为准）。

## 尚未完成

- Gazebo + MoveIt2 的真实规划、执行、碰撞检测和轨迹回取（纯 Python 虚拟工作单元不替代该项）；
- 真实仿真场景中的视觉/几何评价和 P0/P1 重复对照；
- ArmPi 实机 Bridge、参数化 wrapper、视觉评价器和停止链路；
- 能支持“成功率提高”“路径更优”主张的独立实验数据；
- 面向评委的长期在线部署地址和稳定现场运行。

## 数据真实性边界

1. `mock` 结果是确定性软件测试数据，不是实验仪器测量；
2. `simulation_runtime_verified` 在本项目中表示纯 Python 确定性虚拟工作单元，不表示 Gazebo/MoveIt2 或物理动力学；
3. `simulation_runtime_unverified` 只表示 legacy 仿真适配器契约已加载但运行时未验证；
4. 历史轨迹回放是只读展示，不代表当前设备在线，也不发送运动命令；
5. 本提交不包含任何 `real_arm` 成功案例，不生成或修改 `real_arm` JSON、日志或图片；
6. Qwen 的自然语言输出不能替代安全检查、确定性评价器或原始数据。

## 对官方验收的影响

若官方仅检查“可调用 API、交互前端、源代码、环境和软件逻辑”，本包可作为软件原型提交；若认可软件虚拟工作单元，也可展示 `simulation_runtime_verified` 的确定性闭环，但必须披露其合成模型假设。若官方要求 Gazebo/MoveIt2 或真实仪器的“实验运行与数据获取”以及可复验反馈收益，则当前版本仍为“未完成/受阻”，必须补齐对应证据后才可升级结论。

## 补齐条件

将本声明中的状态改为“已验证”前，必须同时提供：

- 同一 Git 提交对应的运行环境和模型版本；
- 至少一条完整 P0→P1 记录，含计划、执行、评价、失败分析、参数差异和同条件检查；
- 仿真或实机的轨迹、碰撞/安全、结果和原始日志；
- 固定条件下足够重复次数（项目内部建议 P0/P1 各至少 10 次）；
- Qwen 调用（若作为官方要求）及脱敏 Request ID、Schema 和哈希证据；
- 可由 `SHA256SUMS.txt` 校验的冻结提交包。
