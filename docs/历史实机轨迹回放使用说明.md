# 历史实机轨迹回放使用说明

## 目的

本功能把硬件侧已经采集的 ArmPi 运行包作为**只读历史证据**加载到上层控制台，用于检查关节轨迹、动作阶段和视觉日志字段。它不会连接机械臂、不会发布 ROS 指令，也不会根据轨迹推断抓取成功率。

当前支持：

- 已解压的单次运行目录；
- 包含多个运行目录的目录；
- `.tar`、`.tar.gz`、`.tgz` 历史运行包。

## 启动

使用项目提供的 Python 运行时，在启动网页时指定历史运行包：

```sh
PYTHON=${PYTHON:-python3}
$PYTHON -m roboscientist.web.server \
  --port 8001 \
  --replay-source /path/to/grasp_run_20260513_123541.tar.gz
```

也可以使用环境变量：

```sh
export ROBO_REPLAY_ROOT=/path/to/grasp_run_20260513_123541.tar.gz
$PYTHON -m roboscientist.web.server --port 8001
```

浏览器打开 `http://127.0.0.1:8001`。页面的“动作画面与历史轨迹回放”区域会显示：

- 数据来源是否为 `historical_real_arm`；
- 回放是否只读；
- 关节位置随时间变化的曲线（页面默认最多展示 200 个采样点，原始点数仍保留在指标中）；
- 视觉日志中解析出的目标坐标和形状；
- 关节空间时长、总行程和原始样本数量；
- 缺失的事件结果、图像或标定证据。

页面中的“回放数据”选择框可以在历史运行包与当前实验记录之间切换。点击“播放关节轨迹”只移动页面上的时间游标，不会调用 `/api/tasks`、ROS、bridge 或任何舵机接口；当前实验记录仍只回放后端已经返回的动作事件。

## API

列出已配置的运行：

```sh
curl http://127.0.0.1:8001/api/replay
```

读取某次运行：

```sh
curl 'http://127.0.0.1:8001/api/replay/<run_id>'
```

或者：

```sh
curl 'http://127.0.0.1:8001/api/replay?run_id=<run_id>'
```

返回中的以下字段是安全边界的一部分，不能删除：

```json
{
  "status": "available",
  "data_source": "historical_real_arm",
  "read_only": true,
  "motion_requested": false
}
```

`trajectory` 是经过上限采样的关节状态点，`metrics` 只表示关节空间统计。若 `events.csv` 为空或没有结果标签，响应会列出限制，前端也必须显示“无法由本次历史包推断成功率”。

## 与真实实机的区别

历史回放不是实时视频，也不是当前设备连接状态。只有硬件侧提供按项目合同运行的 bridge、当前标定、视觉评价和完整 P0/P1 证据后，才可以切换到 `real_arm` 联调。回放接口不具备执行和停止能力，停止按钮仍只面向经安全验证的实机 bridge。
